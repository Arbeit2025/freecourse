# freecourse — 無料講座の横断検索アグリゲーター＋修了証メーカー

無料オンライン講座をまとめて探せる小さなWebツールです。

厳選した無料講座の内蔵カタログ（48件）に加えて、検索するとサーバー側で
複数の講座プラットフォームの公開カタログへ並行に問い合わせ、結果を
統合・重複除去して返します。受講の進捗管理と、本ツール独自の
修了証（学習記録証）の発行もできます。

## できること

- **横断検索**：キーワードを入れると、内蔵カタログ＋外部ソース
  （Coursera／Microsoft Learn／Stepik）をまとめて検索。結果には講座名、
  提供元、レベル（分かるもののみ）、実際の講座ページへのリンクを表示。
- **内蔵カタログの絞り込み**：8カテゴリ（IT・プログラミング／ビジネス／
  語学／デザイン／教養・学問／資格・キャリア／健康・生活／創作）×6件＝48件を、
  キーワード・カテゴリ・レベル（入門／初級／中級）・修了証の有無で絞り込み。
- **進捗管理**：各講座に「受講中／完了」を付けられ、ブラウザの
  localStorage に保存されます。内蔵講座はID、検索結果の講座は
  URL＋タイトルをキーにして区別します。
- **修了証メーカー**：完了にした講座について、氏名を入力すると
  印刷向けの修了証ページ（氏名・講座名・日付入り）を表示します。
  内蔵講座・検索結果の講座のどちらにも発行できます。
- ライト／ダーク両対応、横スクロールなしの簡素なデザイン。

## 横断検索の仕組み

検索時にサーバー側で各ソースへ並行問い合わせし、URL（正規化後）と
「タイトル＋提供元」で重複を除去して統合します。1つのソースが落ちても
他のソースの結果は返し（障害分離）、外部ソースが全て失敗した場合は
内蔵カタログの結果だけを返します。取得結果は短時間キャッシュします
（Courseraスライス・Stepik結果は5分、Microsoft Learnは1時間）。

### 採用ソース（いずれもAPIキー不要・実応答を確認済み）

| ソース | 取得方法 | 無料の扱い |
|---|---|---|
| 内蔵カタログ | 本アプリ内の厳選48件 | 受講無料の講座のみ収録。修了証の有無（無料あり／有料／なし／要確認）を併記 |
| Coursera | 公開カタログAPI | 料金はAPIから判定できないため「無料」とは表示せず、提供元情報のまま表示 |
| Microsoft Learn | Catalog API | 全編無料のため「無料」バッジを表示 |
| Stepik | 公開API | `is_paid=False` の講座だけを取り込み「無料」バッジを表示 |

Coursera についての注意：公開APIの検索機能（ファインダ）は廃止されているため、
カタログの先頭スライス（300件）を取得してキーワード一致をローカルで抽出しています。
Coursera 内の全講座を網羅する検索ではない点にご注意ください。

外部ソースの講座は英語タイトルが中心です。日本語キーワードでは
内蔵カタログが中心にヒットします。

### 不採用ソース（理由）

- **MIT OpenCourseWare**：公開APIが無く、検索ページがJavaScript描画のみで
  サーバー側から結果を取得できないため（講座自体は内蔵カタログに1件収録）。
- **OpenLearn（The Open University）**：この環境から接続失敗→403となり
  安定した応答が得られないため（同上、内蔵カタログに1件収録）。
- **Class Central**：403でbotアクセスが遮断されるため。
- **edX**：カタログAPIが404となり、キーなしでは取得できないため。
- **SWAYAM**：キーなしで使える公開APIを確認できなかったため。

## 「無料」の表示について

- 「無料」バッジは、ソース側で無料と確認できたもの（Microsoft Learn、
  Stepikの無料講座）にだけ付けています。
- Coursera のように料金が判定できないものは「無料」と断定せず、
  ソースの情報（講座名・提供元）をそのまま表示します。
- 内蔵カタログの修了証情報は収録時点の公開情報に基づく目安です。
  不確かなものは「要確認」としています。受講料・修了証の条件は
  変わることがあるため、最新の情報は各講座ページでご確認ください。

## 修了証の位置づけ

本ツールが発行する修了証は、学習の記録を手元に残すための
**学習記録証**です。各講座の提供元が発行する公式修了証では
ありません。就職・進学等の証明書類としては使えません。
修了証ページにはその旨を明記しています。

## 技術構成

- Python / Flask（単一ファイル `app.py`。外部HTTP取得は標準ライブラリ
  `urllib` を使用し、追加の依存はありません）
- テンプレートは Flask の `render_template_string`、進捗は localStorage
- 本番起動：gunicorn（`render.yaml`、Render Free プラン想定）
- テスト：pytest（`tests/test_app.py`。外部APIにはアクセスせず、
  パース処理はフィクスチャJSON、統合・障害分離はフェイクで検証）

## ローカルでの動かし方

```bash
pip install -r requirements.txt
python app.py            # http://localhost:5000
# または
gunicorn app:app
```

テスト：

```bash
python -m pytest tests/ -q
```

## ファイル構成

- `app.py` — 本体（内蔵カタログ、横断検索、各ソースのアダプタ、画面、修了証）
- `requirements.txt` — flask / gunicorn
- `render.yaml` — Render デプロイ設定（Free、healthCheck: /healthz）
- `tests/test_app.py` — テスト一式
